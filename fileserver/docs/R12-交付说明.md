## 三、已知问题与教训（诚实记录）

1. **两次自激循环事故**：MutationObserver 回调内无条件写 `textContent` 触发循环。
   处置：立即回滚 + 改为"判等再写 + 节流"。结论已写入本文档。
2. **误判"局数记 2 次"**：实际游戏本就有 runs 字段，我重复累加。
   教训：改计数逻辑前先打印真实存档结构。
3. **测试假失败**：固定 sleep 采样、fixture 依赖外部创建、直接跳终态 URL、
   断言格式不符（`0:03` vs `12:34`）。均已修正为"等待条件/自带 fixture/真实操作序列/贴合格式"。
4. **前端类型筛选前两版失败**：改行 display（被 React 重渲染覆盖）、只改 query（不重取数据）；
   第三版用"fetch 包装 + 强制重挂载"成功，代价是约 40ms 路由闪烁。
