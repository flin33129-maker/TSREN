# 办公工作区（Feishu-like）交付说明

更新时间：2026-10-22
范围：`public/work.html`（前端单页）+ `lib/docs.js` + `/api/docs*`、`/api/share/*`（后端）

## 一、为什么重做

原办公页只有 19KB、4 个静态区块、无编辑器，且 `#/office` 由主站覆盖层（r12Suite）渲染，
出现两个问题：

1. **iframe 未撑满**：覆盖层浅色背景从下方露出，视觉上像"页面只显示一半"；
2. **功能不全**：没有文档/表格/看板/演示等真正的工作能力。

## 二、现在的结构

```
#/office（主站内嵌）
└─ r12-host 覆盖层（深色底、flex 列）
   └─ iframe /work.html?embed=1   ← 100% 填满
      └─ 办公工作区（单文件应用）
         ├─ 左侧：文档 / 表格 / 看板 / 演示 / 日历 / 最近 / 模板
         ├─ 中间：列表（文件夹 chips + 搜索）
         └─ 右侧：工作区（按类型渲染）
```

## 三、能力清单

| 模块 | 能力 |
|---|---|
| 文档 | 富文本编辑（加粗/斜体/下划线/H2/列表/引用/代码/链接）、800ms 自动保存、Ctrl+S、字数统计、导出 Markdown、评论（单机）、文件夹归属、只读分享 |
| 表格 | 可编辑网格、公式（`=A1*B2`、`=SUM(A1:A3)`、`=AVG`）、真实合计行、增行/增列、刷新后重算 |
| 看板 | 待办/进行中/已完成三列、卡片拖拽跨列、卡片内联编辑、删除、优先级 P0-P3、截止日期（逾期标红） |
| 演示 | 多页幻灯片、缩略图列表、标题+正文编辑、新增/删除页、全屏播放（←/→ 翻页、Esc 退出） |
| 日历 | 月视图，按更新日期展示当月文档 |
| 最近 | 按更新时间排序 |
| 模板 | 6 套：周报、会议纪要、需求文档、项目复盘、OKR、数据日报 |
| 搜索 | 标题 + 正文实时过滤 |
| 文件夹 | chips 筛选、新建继承当前文件夹、文档内可改归属 |
| 分享 | 生成只读 token，`/work.html?share=<token>` 免登录只读查看 |

## 四、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/docs?type=doc\|sheet\|board\|slide` | 列表（不含正文） |
| GET | `/api/docs/item?id=` | 单条（含正文/评论） |
| POST | `/api/docs/save` | 新建或更新（id 为空则新建） |
| POST | `/api/docs/remove` | 删除（仅本人） |
| POST | `/api/docs/share` | 生成只读分享 token |
| POST | `/api/docs/unshare` | 撤销分享 |
| GET | `/api/share/<token>` | 免登录读取分享内容（只读） |

存储：`data/docs/<username>.json`，字段 `{id,type,title,content,folder?,comments?,updatedAt}`；
分享表：`data/docs/shares.json`（token → 用户/文档）。单用户上限 300 条，正文上限 512KB。

### 命令面板接入方式

主站注入 IIFE 监听 `Ctrl/Cmd+K`，渲染固定覆盖层（不参与布局，无跳动）；
搜索文档时调 `/api/docs` 过滤标题；选中后 `location.hash='#/office'` 并向 iframe
`postMessage({type:'dsh-open-doc', id})`，办公页按文档类型切到对应视图并打开。

## 十一、协作能力（追加）

### 实时同步（SSE）

| 项 | 说明 |
|---|---|
| 订阅 | `GET /api/docs/events?cid=<客户端ID>`，`text/event-stream`，25 秒心跳 |
| 广播 | `POST /api/docs/save` 成功后向同一用户的全部订阅端推送 `{id, updatedAt}` |
| 客户端行为 | 非编辑状态自动替换正文并提示「已实时同步」；编辑中提示「他人已更新 · [同步]」 |
| 兜底 | 保留 2.5 秒轮询，SSE 断线仍可同步 |
| 实测 | 外部保存 → 页面更新延迟 **< 2 秒**（验证脚本断言 <2.0s） |

### 在线人数（presence）

| 项 | 说明 |
|---|---|
| 上报 | `POST /api/docs/presence {cid, id}`，打开文档时上报，此后每 15 秒续约 |
| 统计 | 服务端按同文档去重 cid 计数，广播 `{type:'presence', id, count}` |
| 展示 | 文档状态栏徽标「👥 N 人在看」 |
| 实测 | 打开显示 1 人；模拟第二端加入后显示 2 人 |

### 其他协作/导出

- 评论支持**回复**（缩进展示、随文档持久化）
- 文档**图片上传**（≤300KB，转 data URI 插入）
- 表格**复制为 TSV**（含公式计算结果，可直接粘进 Excel）
